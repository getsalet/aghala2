# بسته چندزبانه Navar نسخه ۳

## مسیرهای قطعی

- فارسی: `/slug/`
- عربی عراق: `/iraq/slug/`
- تاجیکی: `/tj/slug/`
- انگلیسی: `/en/slug/`
- روسی: `/ru/slug/` (از نسخه 3.1؛ دسته با نامک `ru` توسط SQL ترجمه روسی در صورت نبودن ساخته می‌شود)

مسیر قدیمی `/iq/slug/` فقط با یک ریدایرکت مستقیم ۳۰۱ به `/iraq/slug/` هدایت می‌شود.

## نصب

1. افزونه `navar-multilingual-permalinks` نسخه ۳ و افزونه سایدبار نسخه ۲ را جایگزین نسخه‌های قبلی کنید.
2. فایل اصلاح‌شده `footer.php` را در نسخه سفارشی GeneratePress قرار دهید.
3. دسته‌ای با نامک `en` یا `english` ایجاد کنید.
4. تنظیمات «پیوندهای یکتا» را یک بار بدون تغییر ذخیره کنید.
5. همه کش‌های وردپرس، سرور و CDN را پاک کنید.
6. URLهای `/iq/`، `/iraq/`، `/tj/` و `/en/` را با ابزار Redirect Path یا `curl -I` کنترل کنید.

افزونه برای نسخه‌های ترجمه‌شده تگ‌های `hreflang` پنج زبان و `x-default` تولید می‌کند.
